# After Effects Project Cleanup Tool

**English Description:**

An advanced tool for automating system cleanup after completing After Effects projects. This application provides intelligent file sequence processing, safe deletion/moving operations, and comprehensive reporting capabilities.

**Key Features:**
- 🎯 **Intelligent sequence processing** - Automatic recognition and handling of file sequences as single units
- 🛡️ **Safety features** - Dry run mode, backup lists, detailed logging
- 📊 **Comprehensive reporting** - HTML reports with statistics and operation history
- 🖥️ **User-friendly GUI** - Intuitive interface with progress tracking
- 🔧 **Flexible filtering** - File type exclusion, size filtering, and custom rules
- 📁 **Dual operation modes** - Delete or move files to specified locations

**Requirements:** Python 3.7+, Windows 10/11, tkinter (included with Python)

**Quick Start:**
1. Generate a report from After Effects: `File > Dependencies > Collect Files > Generate Report Only`
2. Run `python ae_cleanup_gui.py`
3. Select your report file and configure operation parameters
4. Execute cleanup operation with real-time progress tracking

## Використання

### 1. Підготовка звіту After Effects

1. Відкрийте ваш проект в After Effects
2. Перейдіть до `File > Dependencies > Collect Files`
3. Виберіть опцію `"Generate Report Only"`
4. Збережіть звіт у зручному місці

### 2. Запуск інструменту очистки

1. Запустіть `ae_cleanup_gui.py`
2. Натисніть "Вибрати файл звіту" та оберіть створений звіт
3. Налаштуйте параметри операції:
   - **Операція**: Видалення або Переміщення
   - **Цільова папка**: Для переміщення файлів
   - **Фільтри**: Виключення типів файлів, фільтрація за розміром
   - **Безпека**: Dry Run, резервні списки, обробка секвенцій

### 3. Виконання операції

1. Натисніть "Почати операцію"
2. Підтвердіть операцію (якщо не Dry Run)
3. Слідкуйте за прогресом в інтерфейсі
4. Перегляньте згенерований звіт

## Детальний опис модулів

### AECleanupCore
Основний модуль з логікою обробки файлів:
- Парсинг звітів After Effects
- Застосування фільтрів
- Виконання операцій видалення/переміщення
- Управління статистикою

### FileSequenceParser
Інтелектуальний парсер секвенцій:
- Розпізнавання масок файлів (наприклад, `[00000-00447].png`)
- Валідація секвенцій
- Обробка допоміжних файлів
- Підрахунок розмірів секвенцій

### AEReportGenerator
Генератор звітів:
- Створення HTML звітів з красивим дизайном
- JSON експорт для програмної обробки
- Статистика використання диска
- Історія операцій

## Приклади використання

### Базове видалення файлів
1. Завантажте звіт After Effects
2. Виберіть операцію "Видалення"
3. Увімкніть "Dry Run" для тестування
4. Запустіть операцію

### Переміщення з фільтрацією
1. Завантажте звіт
2. Виберіть операцію "Переміщення"
3. Вкажіть цільову папку
4. Налаштуйте фільтри (наприклад, виключіть .aep файли)
5. Запустіть операцію

### Робота з секвенціями
1. Увімкніть "Обробляти секвенції"
2. Програма автоматично розпізнає файлові секвенції
3. Секвенції будуть оброблені як єдині елементи

## Безпека та відновлення

### Резервні списки
При виконанні операцій (не в Dry Run режимі) автоматично створюються резервні списки у форматі JSON з інформацією про:
- Оброблені файли
- Секвенції
- Статистику операції
- Час виконання

### Логування
Всі операції записуються в детальні логи з інформацією про:
- Успішно оброблені файли
- Помилки та їх причини
- Пропущені файли
- Статистику виконання

## Налаштування та конфігурація

### Фільтри файлів
- **Виключені розширення**: Список розширень через кому (наприклад: `.aep,.prproj,.psd`)
- **Мінімальний розмір**: Файли менше вказаного розміру будуть пропущені
- **Максимальний розмір**: Файли більше вказаного розміру будуть пропущені

### Параметри безпеки
- **Dry Run**: Тестовий режим без реальних операцій
- **Резервні списки**: Створення списків для відновлення
- **Збереження .aep**: Автоматичне виключення файлів проектів
- **Обробка секвенцій**: Інтелектуальна обробка файлових послідовностей

## Усунення неполадок

### Поширені проблеми

**Помилка "Файл звіту не знайдено"**
- Перевірте правильність шляху до файлу
- Переконайтеся, що файл не заблокований іншою програмою

**Помилка доступу до файлів**
- Запустіть програму від імені адміністратора
- Перевірте права доступу до файлів та папок

**Повільна робота з великими проектами**
- Використовуйте фільтри для зменшення кількості файлів
- Закрийте інші програми для звільнення ресурсів

### Логи та діагностика
Логи зберігаються в файлі `ae_cleanup.log` в папці програми. Для детальної діагностики:

1. Увімкніть детальне логування
2. Запустіть операцію в Dry Run режимі
3. Перевірте логи на наявність помилок
4. Зверніться до документації або підтримки
